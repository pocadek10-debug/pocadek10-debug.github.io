Privacy Policy

Paper Trail. Last updated: 2026-11-12

What this application is

The Paper Trail application is an internal tool used only by the owner of the Paper Trail YouTube channel. It is not offered to the public, and no one else signs in to it.

How it uses YouTube API Services

The application uses YouTube API Services to:

  • upload videos to the owner's own Paper Trail channel and set their thumbnails and video settings;
  • read statistics of the owner's own channel and videos.

By using this application you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data we collect

The application does not collect personal data from viewers or from any third party. It only accesses the channel owner's own YouTube account, with the owner's consent. The authorization token is stored on the owner's own computer and is used only for the purposes listed above.

Sharing

We do not share, sell or transfer any data obtained through YouTube API Services to anyone.

Revoking access

The owner can revoke the application's access at any time in the security settings of their Google Account, where third-party apps with account access are listed.
